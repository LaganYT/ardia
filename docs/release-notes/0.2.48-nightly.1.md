headline: Hide Element saves only what you picked.

## Fixed

- **A web page can no longer turn Hide Element against you.** A page could make Ardia save a rule that ran its own
  script on every site you visit. Ardia now saves a hidden element only as a plain selector for the site you are on,
  and removes any such rule a profile already holds before your pages load. Hide Element still works from the View
  menu and from a right-click, inside frames too.

## New

- **A two-finger swipe on the toolbar goes to the previous or next tab.**
- **⌃Tab switches tabs the way Chrome does,** and the switcher's cards no longer flash white.
